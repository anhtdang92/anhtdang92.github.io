ATLAS — Stock ML Intelligence System

atlas-ml-trading

An LSTM that forecasts 21-day stock returns from 34 technical indicators, tested against six other architectures and simple baselines with Optuna tuning and walk-forward cross-validation. Served through FastAPI and Vertex AI, packaged with Docker, with a Streamlit dashboard.

  • 7-architecture ablation
  • Walk-forward CV
  • Bootstrap CIs + Diebold-Mariano
  • 150+ tests · model card

ARGUS

argus

Open-source cyber threat detection platform. The architecture and model code are written: an LSTM-autoencoder → Isolation Forest → XGBoost anomaly ensemble for CICIDS2017 and UNSW-NB15, a GNN for lateral movement on LANL auth logs, SHAP explanations, and NER for IOCs. The roadmap phases aren't finished and no trained models are committed yet.

  • PyTorch
  • PyTorch Geometric
  • XGBoost
  • SHAP
  • FastAPI
  • Neo4j
  • Next.js
